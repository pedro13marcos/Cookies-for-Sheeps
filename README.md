# 🍪 Cookies for Sheeps (Cookies & Ovelhas)

> **Unidas contra João | United against John | Unidos contra Juan**  
> **Status**: `pre-alpha 0.13`

A 2D top-down action/adventure game built with the **Godot Engine 4**.

---

## 📖 Story & Gameplay

Control **Shakira**, a brave sheep on a mission to rescue her sister **Dublínia** from the clutches of **João (John)**!

- **Dodge Obstacles**: João drops dangerous substances designed to slow you down.
- **Collect Cookies / Bread**: Pick up dropped cookies to boost your movement speed.
- **Fight Back**: Throw cookies at João by pressing the action button. Hit him 3 times in each encounter to make him flee and progress toward Dublínia!

---

## 🎮 Controls

The game features automatic controller detection with support for Keyboard/Mouse and Gamepads:

| Action | Keyboard | PlayStation Controller | Xbox Controller |
| :--- | :--- | :--- | :--- |
| **Move** | `W`, `A`, `S`, `D` / Arrow Keys | D-Pad / Left Stick | D-Pad / Left Stick |
| **Attack (Throw Cookie)** | `F` | `Square` | `X` |
| **Confirm / Next** | `Space` / `Enter` | `Cross` (✕) | `A` |
| **Pause** | `Esc` | `Options` | `Menu` |

## 🚀 Getting Started

### Prerequisites

- [Godot Engine 4.2+](https://godotengine.org/download)

### Running the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/pedro13marcos/Cookies-for-Sheeps.git
   ```
2. Open **Godot Engine**.
3. Click **Import**, navigate to the project directory, and select `project.godot`.
4. Click **Run Project** (or press `F5`).
